For People No Friend V1.7 基础包

这是不带预设角色的空白软件包：
- 不包含小猫、凯尔希或其他身份卡；
- 不包含内嵌 Live2D 或 VTube Studio 模型；
- 不包含伊蕾娜或其他指定音色权重；
- 不包含 Python、本地 TTS/ASR 推理环境、日语 BERT 或 SenseVoiceSmall 模型。

首次进入会显示中性的“桌宠”占位资料，角色显示默认关闭。你可以在设置中创建或
导入身份卡，并选择以下任一显示方式：导入 .model3.json、连接 VTube Studio，或
使用 ViewerEX。身份卡使用应用内导入，不需要手工寻找 AppData。

为避免 Windows 路径过长，建议把整个 FPNF 文件夹解压到较短的位置，例如：
C:\FPNF

不安装本地语音组件时，文字聊天、在线或用户自建的 OpenAI 兼容语音接口、
Genie-TTS 和 Fish Audio 仍可正常配置。需要完全离线的本地语音输入或
Style-Bert-VITS2 时，再单独下载“Local-Speech-Runtime”组件。

可选资源必须保持压缩包内的相对目录结构。请先退出 FPNF，再把可选资源压缩包内的
FPNF 文件夹与本体的 FPNF 文件夹合并，然后重新启动软件。
