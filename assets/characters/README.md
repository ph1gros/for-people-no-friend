# 角色表现资源

角色表现包使用带版本的本地清单。把新的透明动态 WebP 放入对应版本的 `media` 目录，文件名尽量使用“动作_情绪_细节”，然后运行 `pnpm character:catalog`。

生成器会检查 WebP 签名、透明通道、动画帧、正方形尺寸、数量和通道引用，并自动补充动作、情绪、道具、姿势和速度标签。不同原始分辨率统一放进角色包声明的逻辑画布显示，不会覆盖源文件。

`presentation.scale` 是角色在窗口内的独立画面占比，允许范围为 `0.4`～`1`。它只缩放角色素材和贴合边框，不改变用户设置的桌宠窗口大小；可用于让不同素材包切换后保持接近的视觉体量。

每个角色包必须声明 `idle`、完整情绪回退、作者、来源和使用条件。运行时只读取清单内的安全相对路径，不加载来源页面上的远程素材。
