# V1.2 / M6：GIF Version 角色生成与表现闭环

## 完成范围

GIF Version 以伊雷娜作为动态 WebP 完整示例，补齐可追溯角色资料、轻量提示预算、表现恢复优先级和失败回退。它继续拥有联网生成角色草稿的能力，但不会加载或切换到 `main` 的凯尔希 Live2D 示例。

## 轻量角色生成

- 用户只提交确认过的角色名和作品名；公开资料由 Main Process 查询。
- 模型整理结果先成为带来源的本地草稿，用户点击保存后才替换当前角色资料。
- 角色资料、作品词库、私人对话、长期记忆和 WebP 素材分别使用独立结构与命名空间。
- SQLite v5 按字段保存身份、性格、经历、关系、情境、说话规则、短句及来源证据。
- 普通聊天最多保留 12 条、12,000 字近期消息；角色资料固定身份和说话规则，再补一条相关资料，总计最多 3 条、1,400 字；单轮输出上限为 640 token。
- 资料库缺失、版本不一致或损坏时回到已验证角色卡，不阻断文字聊天。
- 联网候选使用“角色名 + 来源作品或作者 + 角色资料”组合查询；标题必须包含角色名，摘要必须匹配来源，角色列表和同名异作页面不能直接成为候选。
- 候选来源按作品官方、专属社区 Wiki、萌娘百科、百度百科、Wikipedia 和普通社区页面分级；搜索摘要只用于发现，保存前仍需读取允许站点并由用户确认。
- 模型单独生成对用户的常用称呼，并使用可容错的 JSON 解析；角色资料整理最长允许 180 秒，失败仍保留手动填写路径。
- 生成另一角色时根据 WebP 模型、正式角色名和来源作品生成稳定人格命名空间；历史、摘要、长期记忆和角色资料随人格隔离，切回同一角色可以恢复原内容。

## 动态 WebP 表现调度

可见资源使用以下优先级：

1. 一次性动作；
2. 当前 `thinking` 或 `talking` 状态；
3. 最近回复的短暂情绪；
4. `idle` 待机。

角色包提供 `enter` 时启动播放入场动作。一次性动作结束后恢复最新状态；思考和说话不会再被上一轮表情压住。回复心情根据最近四条记录延续，画面保持到下一次回复决定新心情；旧情绪线索离开四条窗口后自然回落。未知动作、缺失资源或解码失败仍安全回退，不影响文字回复。

## 自动验收

- 伊雷娜固定检索覆盖身份、芙兰关系、说话方式、低落安慰和辱骂边界；关键词基线为 5/5。
- WebP 测试覆盖动作恢复、状态优先、短暂情绪、透明首帧、素材路径和清单完整性。
- SQLite 测试覆盖命名空间隔离、字段证据、原子替换、级联删除、损坏回退和重启读取。
- IPC 不再暴露跨版本角色列举或激活入口。
- 作品词库同步会主动搜索公开网页，从正文校验社区梗、黑话、别名和台词；最近四条已完成对话可以补全当前词语语境，失败时保留旧缓存。
- 共享设置验收覆盖窗口缩放的滑条到运行时、右键调整到滑条、持久值重载，以及提供商/模型、角色资料、记忆开关和作品词库状态的关闭重开恢复。
- 测试只使用 fake、临时 SQLite 和本地 HTTP，不读取真实 API Key。

## 延期到 V1.3 的真人目视验收

不同缩放、拖动、长回复、启动入场和长时间桌面运行统一延期到 V1.3，不作为 V1.2 的未完成尾项，也不宣称已经人工通过。V1.2 以自动测试、类型检查、构建与 Preload 沙箱检查通过作为收尾条件。
