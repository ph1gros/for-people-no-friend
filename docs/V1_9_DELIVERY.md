## 使用与参考

沿用 Electron、TypeScript、Vite、SQLite、sherpa-onnx 和现有 Genie 语音链路，没有新增生产运行时依赖。Main 继续管理文件、网络、下载校验和宿主调用，Preload 只提供固定接口。试听音频的来源和许可文件随包放在 `resources/licenses/voice-previews/`。

参考 VTube Studio Plugin API、Live2DViewerEX 官方文档、Cubism 参数约定与 emotion-engine 的通道划分；没有复制 GPL 项目的实现到本仓库。psd2live 的格式能力与许可证、Qwen-Image-Layered 等候选的输入输出限制和阶段验收统一记录于研究文档。

## 缺少什么

以下是公开的功能或验收缺口，不通过版本号掩盖：

1. **标准包内嵌 Live2D 运行时**：Cubism Core 的固定官方来源、版本和适用分发条件尚未核定，标准包明确排除它。导入模型不能补齐运行时；用户可采用 VTS/ViewerEX，或具备合适 Core 的本地构建。
2. **工坊一键导入与任意模型语义识别**：本版提供宿主入口和接入指引。下载、作者许可确认、宿主加载和模型专用动作/表情绑定仍需用户处理；没有通用工坊抓取器。
3. **模型表现的实际效果**：自定义参数名、缺少头部绑定、ViewerEX 空映射不能自动获得点头；混合情绪自然度、口型不抢占、恢复和 ViewerEX 执行效果仍需用实际模型确认。
4. **桌面环境矩阵**：多显示器、100%/125%/150% DPI、原生拖动、GPU/软件渲染和真实读屏尚未完成全矩阵；时钟正常退出后跨主进程保持的隔离探针仍在入口前退出，未取得通过证据；DOM `pointer-events` 不代表点击能穿透到其他 Windows 应用。
5. **Astra 正式接入**：流式接缝、长句稳定性、服务端取消、内存峰值/回收和连续耳听仍有缺口，保持隔离研究，未替换生产语音引擎。
6. **单图到成品模型**：仍是分层、绑定、导出、参数发现与映射确认的分阶段方案；尚未端到端生成并验收一个新模型。psd2live 输出与本项目引擎的兼容性需要实际测试。
7. **社交 PR 与分发体验**：PR #2 的两项已确认问题待其合并前修复；本版不含 QQ/KOOK/Oopz。Windows 包未签名，没有安装器或自动更新。另有 1 项试听音频来源链待核实事项，审查报告已区分它与已确认代码缺陷；随包说明已澄清短录音和未分发权重的区别。

四种音色的用户反馈“语音本身没问题”已经保留，但不扩大为每种音色的全部停止、残音与长句步骤均通过。需要在线服务真实凭据的试听由用户自行配置后验收，自动检查不读取真实密钥。

## 早上验收入口

从 Release 下载 ZIP，完全解压到新目录，退出旧版本后运行 `For People No Friend.exe`。先确认已有配置正常加载，再检查时钟启停、下载前试听与显示模式。对具体模型确认点头/摇头幅度、眨眼和口型是否自然，ViewerEX 先在宿主加载模型并配置有效映射。发现问题时记录显示模式、模型参数/映射、操作和现象即可，不需要提供密钥或私人聊天。
