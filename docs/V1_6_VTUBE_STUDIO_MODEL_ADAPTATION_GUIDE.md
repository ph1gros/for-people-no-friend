# V1.6 VTube Studio 模型接入与调教参考

这份说明记录“小猫”当前模型的接入方法，并作为以后更换 VTube Studio 模型时的校准基线。它不是模型文件格式说明，也不授权复制、导出或再分发任何模型。

## 1. FPNF 与 VTube Studio 各自负责什么

- VTube Studio 负责加载模型、渲染、表情文件和模型自身的参数配置。
- FPNF 只通过官方 Plugin API 连接 `127.0.0.1`，读取当前模型公开的参数、表情与热键，并注入有限的姿态参数。
- FPNF 不读取 VTube Studio 模型目录，不复制模型文件，也不代替 VTube Studio 导出模型。
- 首次连接必须在 VTube Studio 中确认授权；令牌由系统安全存储保存，以后通常不需要重复确认。
- “纯 Live2D”是另一条显示路径：模型由用户明确选择后复制进 FPNF 的本地数据区，可以再从 FPNF 导出。两种显示方式同一时间最多启用一个。

## 2. 接入新模型前

1. 在 VTube Studio 中加载模型，确认模型本身能正常显示。
2. 开启 Plugin API，默认端口为 `8001`；如果改过端口，FPNF 设置中也要一致。
3. 选择“模型显示方式 → VTube Studio”，点击“授权并读取当前模型”。
4. 展开“查看模型参数”，确认参数名称、最小值、最大值、默认值和当前值。
5. 逐个预览模型表情，记录真正对应惊讶、高兴、生气、难过等状态的表情。
6. 决定由 AI 接管时，关闭或暂停 VTube Studio 自己的人脸追踪，防止两个来源同时修改同一参数。

## 3. 当前 FPNF 注入的标准参数

| FPNF 参数 ID   | 用途     | 当前行为                                       |
| -------------- | -------- | ---------------------------------------------- |
| `FaceAngleX`   | 头部左右 | 随机待机、说话变化、鼠标水平跟随               |
| `FaceAngleY`   | 头部上下 | 随机待机、普通点头、犯困点头、鼠标垂直跟随     |
| `FaceAngleZ`   | 头部侧倾 | 缓慢随机变化，避免只做机械左右转动             |
| `EyeRightX`    | 眼球左右 | 随机微动和鼠标水平跟随                         |
| `EyeRightY`    | 眼球上下 | 鼠标向上限制较小，左右与向下比例更明显         |
| `EyeOpenLeft`  | 左眼睁开 | 自动眨眼、慢慢入睡、靠近时微睁、对话时慢慢醒来 |
| `EyeOpenRight` | 右眼睁开 | 与左眼同步                                     |

参数名是 VTube Studio 的标准跟踪输入名，但模型内部可以把它们映射到不同的 Cubism 参数。模型存在同类功能不代表一定使用这些 ID。

## 4. 不能直接照搬 0～1

每个模型的参数范围和默认值都可能不同：

- 睁眼常见范围是 `0～1`，但也可能是其他范围或反向含义。
- 头部角度常见范围是负数到正数，不应当按开关处理。
- 自定义表情参数可能是 `0/1` 开关，也可能需要连续值。
- 同一个表情文件可以同时固定多个参数；FPNF 再注入同一参数时可能互相覆盖。

接入新模型时应先读取清单，再建立“标准功能 → 实际参数 ID → 有效范围 → 中性值”的映射。没有确认范围前，只做短时、小幅预览，不写模型文件。

## 5. 当前“小猫”调教基线

以下数值是 FPNF 的控制幅度，不是要求模型文件使用相同范围：

- 普通待机头部幅度约：X `4.2`、Y `2.4`、Z `3.2`。
- 思考状态稍活跃，讲话状态介于思考和待机之间。
- 随机姿态每约 `2.2～4.8` 秒平滑过渡一次，同时包含 X、Y、Z，不只左右摆动。
- 首次自主小动作约 `18～30` 秒后出现；之后约每 `45～75` 秒一次。
- 普通点头约 `1.2` 秒、幅度 `4`；犯困后首次点头随机等待约 `6～12` 秒，之后每次再随机等待约 `10～24` 秒，单次时长约 `2～3.2` 秒、幅度约 `4～7.5`。
- 自动眨眼间隔约 `2.8～6.5` 秒，单次约 `240` 毫秒。
- 入睡闭眼约 `1.8` 秒；收到消息后约 `2` 秒完全睁开。
- 犯困时眼睛完全闭合；鼠标靠近最多只睁到约 `0.28`，不会立刻完全醒来。
- 眼球水平跟随比例约 `0.5`；向上约 `0.28`，向下约 `0.34`。

如果新模型动作过大，优先降低 FPNF 侧幅度或建立模型专属比例，不要直接改模型源文件。若方向相反，再校正符号。

## 6. 表情、动作与 AI 状态

- FPNF 会读取当前模型在 VTube Studio 中公开的表达式和热键清单。
- 先用设置页逐个预览，确认哪个表情真正可用，再建立情绪映射。
- 表情名称只是线索，不能只靠“happy”“surprise”字样自动认定。
- AI 状态包括待机、思考、说话和动作；表情与动作结束后应恢复到中性状态。
- 点头与犯困属于 FPNF 注入姿态，不要求模型拥有额外的 `.exp3.json`。
- 如果模型自己的表情锁定了眼睛或头部参数，眨眼、鼠标追踪或点头可能暂时不明显。

## 7. 鼠标追踪与休息状态

- 鼠标追踪是独立勾选项；关闭后仍保留自然待机和眨眼。
- 头部跟随比眼球更弱、更慢，避免角色像摄像头一样僵硬锁定鼠标。
- 鼠标离开后逐渐回到随机待机，而不是瞬间归零。
- 超过休息时间后角色只说一次犯困台词，然后闭眼休息，不会循环打扰。
- 鼠标靠近只是“察觉到你”，只微睁眼；真正发送消息才会完全叫醒。

## 8. 常见冲突

### 模型和内置 Live2D 同时出现

确认显示方式只有 VTube Studio 被启用。FPNF 切换到外部显示时应卸载纯 Live2D；不要同时打开两条显示路径。

### 小组件或对话框遮住模型

在桌面布局中调整角色左右位置、组件对齐和对话框位置。布局会做基础避让，但 VTube Studio 原应用窗口的位置与大小仍由 VTube Studio 管理。

### 眼睛不动，只转头

检查模型是否把眼球映射到 `EyeRightX` / `EyeRightY`，以及表情是否锁住眼球参数。也可能模型使用了自定义眼球 ID，需要增加专属映射。

### 不眨眼或睡觉不闭眼

检查 `EyeOpenLeft` / `EyeOpenRight` 是否存在、范围是否正常、方向是否相反，并确认 VTube Studio 人脸追踪没有覆盖注入值。

### 每次连接都要求确认

检查 VTube Studio 是否保留插件授权，以及 Windows 安全存储是否可用。不要把授权令牌写进普通设置或日志。

### 表情预览有用，AI 状态没有反应

先确认表达式能被官方 API 激活，再检查情绪映射；不能用参数名称猜测表情编号。

## 9. 新模型验收清单

- 模型可在 VTube Studio 单独正常加载。
- Plugin API 只监听本机，端口一致，授权成功。
- 能读取模型名、参数、表达式和热键。
- X、Y、Z 三个头部方向幅度自然，没有反向或越界。
- 眼睛可左右、上下跟随；上看不会过度，向下仍清楚。
- 自动眨眼、慢闭眼、靠近微睁、消息唤醒均可见。
- 普通点头轻，犯困点头更明显但不穿模。
- 表情逐个预览后完成映射，结束时能恢复。
- VTube Studio、人脸追踪、纯 Live2D、小组件之间没有同时抢占或明显遮挡。
- 关闭 VTube Studio 模式后停止注入，不影响 VTube Studio 自己使用。

## 10. 安全边界

- Renderer 只能请求“授权、读取、预览、呈现”；端口和所有输入由 Main 再验证。
- 只允许环回地址，不把模型清单、文字、声音或本地路径发往外网。
- 日志不记录授权令牌、API Key、完整本地路径或模型二进制内容。
- FPNF 不自动修改 VTube Studio 模型、表达式或热键配置。
- 模型的使用、导出与再分发仍受原作者许可约束；“能在本机读取参数”不等于“可以重新发布模型”。
