# 公开示例角色包

两个版本各自带一个可以直接研究和修改的公开示例。它们共享角色资料格式、安全边界和本机记忆能力，但不在运行时互相切换。

| 分支          | 示例         | 表现资源                               | 随仓库提供的公开内容                                                                           |
| ------------- | ------------ | -------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `main`        | M3（Mon3tr） | Live2D；模型本体按授权由用户在本机放置 | 身份、背景、关系、说话方式、情境表达参考、资料来源与《明日方舟》作品社区词库                   |
| `gif-version` | 伊雷娜       | 版本化动态 WebP 目录与表情素材         | 素材清单、作者与来源、身份、背景、关系、说话方式、情境表达参考、资料来源与《魔女之旅》作品词库 |

## 公共和私人内容的边界

示例包可以提交公开的角色设定、作品专有名词、来源链接、经归纳的表达特点和公开授权的表现素材。以下内容只留在用户本机，不属于示例包：

- 用户与角色的聊天记录；
- 从聊天中形成的长期记忆、候选记忆和证据消息；
- 会话摘要、API 配置、作品词库联网缓存和窗口状态；
- 未确认可以再分发的第三方 Live2D 模型或运行时文件。

角色资料、作品词库、用户记忆和表现资源使用不同命名空间。删除或替换其中一个，不会悄悄带走另外三个。

当前开发机上的参考外观是作者“什行在要”发布的“工作凯尔希”Live2D，并不是 M3 模型。原页面标注禁止未经授权转载，所以仓库不会复制这套模型，只在 [本地 Live2D 兼容模型说明](../assets/models/README.md)中保留作者与来源。角色资料卡和外观资源故意分开，免得换个名字就把别人家的猫认成另一只。
