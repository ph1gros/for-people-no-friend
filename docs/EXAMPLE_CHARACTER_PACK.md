# 公开示例角色包

两个版本各自维护一个可以直接研究和修改的公开示例，运行时不跨表现层切换。

| 分支          | 示例         | 表现资源                                   | 随仓库提供的公开内容                                                                           |
| ------------- | ------------ | ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `main`        | M3（Mon3tr） | Live2D；模型本体按各自授权由用户在本机放置 | 身份、背景、关系、说话方式、情境表达参考、资料来源与《明日方舟》作品词库                       |
| `gif-version` | 伊雷娜       | 53 个版本化动态 WebP 表情                  | 素材清单、作者与来源、身份、背景、关系、说话方式、情境表达参考、资料来源与《魔女之旅》作品词库 |

## 伊雷娜示例包含什么

- `assets/characters/irena/v1/media/`：用户提供并确认获授权分发的 53 个动态 WebP 文件；
- `pack.config.json`：待机、思考、说话、情绪和动作的稳定映射；
- `character.json`：素材尺寸、动画帧、透明通道、SHA-256 与多标签清单；
- 内置伊雷娜资料卡：称呼、身份、背景、性格、关系、说话方式、情境表达参考与来源；
- 内置《魔女之旅》词库：灰之魔女、妮可冒险谭、星尘魔女和魔法统筹协会等作品专名。

素材作者为 [白之魔女-霜娜](https://space.bilibili.com/2125763952)，原始发布页见[这条动态](https://www.bilibili.com/opus/1209543497317613574)。授权说明同时保存在资源配置和生成清单中。

## 公共和私人内容的边界

示例包只包含公开的角色设定、作品专名、来源链接、经归纳的表达特点和获准分发的表现素材。以下内容只留在用户本机：

- 用户与角色的聊天记录；
- 从聊天中形成的长期记忆、候选记忆和证据消息；
- 会话摘要、API 配置、联网词库缓存和窗口状态。

角色资料、作品词库、用户记忆和表现资源使用不同命名空间。公开角色短句或情境例子只是扮演参考，不会冒充用户曾经说过的话。
