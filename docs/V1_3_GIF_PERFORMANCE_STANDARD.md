# V1.3 GIF Version 表现标准

状态：自动规则与基础测试已实现；伊雷娜真人目视验收仍待完成。

## 新素材标签

- 文件名只生成候选，不直接改写角色清单。
- 一个素材可同时具有格式、状态、情绪、动作和质量标签。
- 候选记录标签、置信度和判断原因；没有明显线索时只保留格式标签。
- 用户预览并确认后才能进入 `states`、`emotions` 或 `actions` 映射。
- `idle` 必须始终存在；缺失、解码失败或未知标签回到待机，不阻断文字聊天。

## 播放优先级

优先级为“一次性动作 > thinking/talking > 回复情绪 > idle”。一次性动作结束后恢复当前仍有效的情绪；thinking 和 talking 结束后也恢复情绪，而不是清空图片。

- `idle`：没有生成和一次性动作时的稳定回退；
- `thinking`：请求已发出但正文尚未返回；
- `talking`：正在显示回复正文；
- `emotion`：经过校验的回复情绪，可在最近四条记录内有限延续；
- `action`：角色清单明确允许的一次性动作。

同一动作按队列播放，播放时长取资源清单的 `durationMs`；错误、超时或素材缺失后恢复最新状态。旧情绪不会覆盖当前明确的新情绪，也不会写进长期记忆或关系等级。

## 自动验收

- 新文件候选始终要求人工确认；文件名可以产生多个标签。
- 待机、思考、说话、情绪和一次性动作缺失时均有固定回退。
- 最近四条记录保持有限情绪连续性，明确的新情绪可以覆盖旧情绪。
- 测试使用本地清单和 fake 图片驱动，不读取 API Key 或私人对话。
