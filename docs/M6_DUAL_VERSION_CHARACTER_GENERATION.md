# M6：双版本角色生成收尾

M6 不是安装包里程碑。它收尾的是 Live2D Version 与 GIF Version 各自生成角色、保存资料和驱动本版本表现资源的闭环。

- 两边共享带来源的角色资料 schema、候选消歧、用户确认后保存、SQLite 命名空间隔离和安全回退。
- `main` 面向大型模型与长期陪伴，采用较丰富的相关资料、可信记忆和 Live2D 表现联动。
- `gif-version` 面向本地小模型与快速上手，采用紧凑角色资料预算和现有安全待机回退；完整 WebP 标签判定与动作优先级留到 V1.3。
- 两个版本的待机、思考、说话、情绪、动作、共享设置同步与失败回退应保持能力对齐；Live2D 可以使用 Motion、Expression 和参数层提供更完整的实现。
- 共享角色资料格式不等于共享外观：Live2D 只接受 Live2D 清单，GIF Version 只接受版本化动态 WebP 清单。
- 凯尔希和伊雷娜不会在同一个运行时互切；新增角色也只能在当前版本内部发展。
- Embedding、Qdrant 和 Neo4j 仍是可选评估，不是基础聊天依赖，也不进入用户长期记忆。
- M6 不包含安装包、发布、语音、Agent、MCP、屏幕观察或桌面控制。

真人发烟测试可以延后，但必须明确列出未测项；自动测试、类型检查、构建和 Preload 安全检查仍是完成条件。
