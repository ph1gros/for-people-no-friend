# v1.7.1 Release 说明

本版发布此前已完成的布局、稳定性、语音安全修正和主程序精简工作。资源中心、独立 BERT/音色组件及相应资源仓库接入继续开发，不包含在本版中。

## 主要变化

- Live2D 默认构图按实际可见底边定位，小组件按实际高度预留空间；显示方式按旧画面退出、新画面进入的顺序切换。
- 本地 SenseVoice 识别改用 `sherpa-onnx-node`，无需随主程序携带 Python ASR 服务；模型权重仍为外部资源。
- 改进诊断日志脱敏、IPC 来源检查、存储写入串行化、SQLite 备份及可选服务错误处理。
- 语音资产信任记录固定在应用源码；远程清单不得定义哈希、大小或目标。未配置可信记录时停止下载。
- 崩溃清理保留可能仅存的备份及续传分片；清单失败后可重试；自动下载仅允许明确非计费网络，手动操作刷新流量提示。
- 提取聊天时间线、输入区及 DOM 元素工厂；保留元素属性赋值顺序和逐标签类型检查。
- 主程序只保留中英文语言包及必要运行组件，裁剪未用的 WebGPU DLL。

## 下载与使用

附件 `FPNF-v1.7.1-Windows-x64.zip` 为 Windows x64 便携包，约 138.8 MiB，解压约 337.7 MiB。最终准确大小见同次发布的 `package-info.json`，校验值见 `SHA256SUMS.txt`。

解压整个 `FPNF` 文件夹后启动 `For People No Friend.exe`。新安装从中性占位资料开始，角色身份和模型由用户自行导入。更新建议使用新目录，保留旧目录中的自备资源；应用用户目录中的已有数据不因解压新包而被删除。

主包有 ASR 原生引擎，不含 Python 环境、SenseVoice/BERT/TTS 模型、伊蕾娜音色、黑猫身份/模型或训练素材。两个生产语音下载记录仍为 `null`；本版不会自动下载或安装这些资源。可连接已有的在线/本机语音服务。历史 V1.7 离线语音附件不属于本次新发布内容。

## 使用与参考

继续使用 Electron、TypeScript、SQLite、Live2D 与 sherpa-onnx；识别适配参考 sherpa-onnx 官方 Node 接口和 SenseVoice 文件布局。角色布局遵循已有 Live2D 可见边界和小组件契约。BetterGI 风格的资源中心不在本版中。

## 验证边界

发布前完整 `pnpm verify` 通过：116 个测试文件、574 项测试，以及 lint、格式、类型检查、构建、Preload 沙箱、sherpa addon 和 SQLite 备份检查。Windows 成品的原生模块加载、语音资产排除检查通过；成品 ASR 使用独立的本地模型正确转写合成音频，不代表模型已包含在主包中。ZIP 逐文件校验内容与打包目录一致。

真实 Live2D 模型在全部缩放/布局下的目视验收、完整 TTS 听感及真实热点切换仍未完成。当前为未签名便携包，不包含安装器或自动升级。
