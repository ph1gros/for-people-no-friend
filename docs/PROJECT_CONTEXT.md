# 项目背景与架构

## 方向

目标是开发一个具有稳定角色表现、自然语音交互和可扩展能力的个人 AI 桌宠。

当前不急于堆叠所有功能。先研究 `my-neuro` 已经实现的模块、运行链路和工程问题，再选择适合自己的产品路线。

## 长期开发规则

后续每个里程碑都先审查用户指定开源项目中对应模块的最新实现，再开始设计和编码。审查至少记录：

- 可以复用的架构原则、协议处理、生命周期、错误恢复和测试方法；
- 参考实现的技术栈、许可证、维护状态与安全假设；
- 本项目采用、独立改写、延期或拒绝的具体结论；
- 与官方 API 或框架文档不一致时，以官方文档和本项目安全边界为准。

参考不是复制。MIT 项目如实际复制代码需保留许可声明；GPL 项目只学习设计和交互，不把实现复制进当前非 GPL 工程；没有明确许可证的代码不复制。任何参考技术仍需通过本项目自己的单元、集成和 Windows 验证。
## 参考项目定位

`my-neuro` 不是单一模型，也不只是 Live2D 显示程序。它是一套把桌面角色、语音服务、LLM、记忆、视觉和插件连接起来的工作台。

典型运行链路：

```text
文字 / 麦克风 / 弹幕 / 插件主动消息
                    ↓
              ASR 与输入处理
                    ↓
         插件拦截、上下文与记忆注入
                    ↓
          LLM 回复、情绪判断、工具调用
                    ↓
            TTS、字幕、表情与动作
                    ↓
             Live2D 或 VRM 桌宠
```

## 参考项目主要模块

### 桌面与角色

- Electron 负责桌面窗口和系统交互。
- Pixi.js 与 Live2D 负责二维角色。
- Three.js 与 VRM 负责三维角色。
- 情绪标签通过配置映射到表情和动作。

### 对话与语音

- LLM 可使用兼容 OpenAI 协议的本地或云端服务。
- ASR 将麦克风音频转换为文字。
- TTS 将回复转换为角色声音。
- 支持字幕同步、按键说话和语音打断。

### 记忆与知识

- 短期对话历史维持当前上下文。
- RAG 检索角色资料和用户资料。
- MemOS、向量数据库或图数据库承担长期记忆实验。

### 插件

插件可以：

- 在消息发送给 LLM 前注入上下文或修改输入。
- 在回复后记录信息、触发表情或执行动作。
- 注册可供 LLM 调用的工具。
- 定时触发主动对话。
- 使用 JavaScript 或 Python 开发。

参考项目内置能力包括主动聊天、日记、记忆、截图、网页搜索、键鼠操作、音乐、日程、直播和游戏接入。

## 参考项目值得借鉴的部分

- 完整的语音对话闭环。
- 情绪标签到表情动作的简单映射。
- JavaScript/Python 插件生命周期。
- 将高风险功能拆成可开关插件。
- WebUI 配置、日志和服务管理方向。
- 本地模型与云端 API 可以替换。

## 需要谨慎继承的部分

- Node、Python、CUDA 和多个本地服务组成的部署链路较复杂。
- 固定端口和固定等待时间容易导致启动不稳定。
- 依赖版本控制不够严格。
- 普通配置与密钥混在同一配置文件中。
- 截图、键盘监听、鼠标控制和代码执行具有较高权限。
- 功能数量很多，但核心陪伴体验仍需要收敛。

## 推荐的功能分层

### 第一层：最小桌宠

- 透明、置顶、可拖动窗口
- 一个 Live2D 或 VRM 角色
- 文字输入和 LLM 回复
- 字幕显示
- 情绪标签驱动表情

### 第二层：自然语音

- TTS
- ASR
- 语音活动检测
- 实时打断
- 音频、字幕和口型同步

### 第三层：角色持续性

- 稳定人格
- 心情状态
- 主动对话节制
- 会话总结
- 基础长期记忆

### 第四层：环境与行动

- 屏幕视觉
- MCP 和工具调用
- 桌面控制
- 日程、音乐和网页操作
- 插件权限与确认机制

### 第五层：扩展场景

- 直播互动
- 游戏陪玩
- 多角色
- 移动端
- 社区插件市场

## 已明确的第一版方向

- Windows 优先，第一版使用 Live2D，不引入 VRM。
- 云端 Claude 首发，同时通过 OpenAI Compatible 预留 Ollama、LM Studio 和其他本地/云端模型。
- 产品核心是私人陪伴桌宠，不扩张为通用 Agent 平台。
- 第一版不主动观察屏幕、不控制桌面，也不加入 MCP、工具执行或主动对话。
- `my-neuro`、Soullink、EchoBot、ZcChat2 与 BongoCat 系列用于学习，不作为直接代码基础。
- 第一版先保证文字、人格、情绪动作和本地数据可靠；语音在长期记忆之后。
- 推荐 16 GB 内存、最低 8 GB；云端模型首段文字应尽快流式显示，本地空闲 CPU 目标低于 3%。
