# 社交存在交付记录（未发布）

本变更基于 v1.8.3 的 `main`，不改变版本号，不包含安装包或 Release。配置操作见[社交存在配置引导](SETUP_WIZARD_SOCIAL_PRESENCE.md)。设计中的 PR 1–6 是功能分期，本次作为一个集成 PR 提交。

## 用户可见范围

- 设置中新增独立「社交存在」页，QQ、KOOK、Oopz 按角色配置，默认全部关闭；保存凭据后显式连接，失败可单独断开或重试。没有新增首次运行向导页面。
- QQ 官方机器人文字收发、语音识别与可选语音回复；KOOK 文字收发，以及显式加入语音房、公开朗读指定文本、停止并离房。不会自动把私人对话播入语音房。
- 同一角色在桌面和主人私聊中保持连续记忆；他人私聊与群聊/频道使用隔离作用域，群聊不召回主人私人记忆。绑定撤销、角色切换和取消使在途旧请求失效。
- 共享记忆的回合串行执行，桌面等待时显示提示；群聊默认要求 @ / 引用，并有频道冷却、队列过期和限流，主人不绕过限额。
- Oopz 提供实验性风险确认、加密凭据保存、桥接生命周期管理与 OneBot 适配。**生产运行时未接入，启动仍被拒绝；进程存活不等于登录或 OneBot 就绪。**

## 安全与兼容

- Main 负责网络、凭据、存储和子进程；Renderer 仅持有窄化 IPC 与脱敏快照。无运行时适配器发现、任意命令入口或自动下载 Python 桥接。
- 新增固定版本依赖：QQ 官方 SDK `@tencent-connect/qqbot-nodejs@1.0.4`、`silk-wasm@3.7.1`、`opusscript@0.1.1`；编码组件按需加载，缺失时不阻塞文字聊天。没有随 PR 发布音色、角色模型或桥接运行时。
- 新配置不修改既有服务商凭据；QQ App ID 更换会清除该角色旧主人绑定和旧 Secret。社交连接默认不自动启动或在角色变更后重连。
- 本次包含两轮审查修复，覆盖 OneBot 畸形帧和旧连接事件、命名空间等待提示、桥接停止失败重试与取消、token 绑定撤销、取消导入不误断连、断开结果 generation 守卫、早退冷却及 KOOK 源码 NUL 转义。
