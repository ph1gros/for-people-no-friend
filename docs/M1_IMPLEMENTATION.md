# M1 桌宠外壳

## 范围

M1 只实现 Windows 桌宠窗口外壳：透明无边框置顶窗口、拖动与等比例缩放、窗口状态持久化、单实例、系统托盘，以及显示器变化后的可见区域恢复。本里程碑不包含 Live2D、Claude 接口、长期记忆、语音、MCP 或桌面控制。

## 行为

- 窗口默认位于主显示器工作区右下方，保持透明、无边框、置顶且不出现在任务栏。
- 拖动窗口主体可移动桌宠；拖动窗口边缘可在 `0.65x` 到 `1.5x` 之间等比例缩放。
- 位置和缩放保存到 Electron 用户数据目录的 `window-state.json`，不进入仓库。
- 关闭窗口等同于隐藏。托盘单击切换显示状态；右键菜单提供显示/隐藏和退出。
- 第二次启动不会创建新实例，而是显示并聚焦已有窗口。
- 启动、显示器增加/移除、分辨率或工作区变化时，窗口会被限制到当前某个显示器的完整可见工作区。原显示器被拔除时回到主显示器。
- 禁止最大化和全屏，避免透明小窗口进入不可靠状态。

## 安全边界

Main Process 独占窗口、托盘、显示器和文件持久化能力。Preload 仍只暴露 `getAppVersion()`，本里程碑没有新增 IPC 通道。Renderer 保持 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，并拒绝导航、新窗口、WebView 和权限请求。

## 本地验证

自动验证：

```powershell
pnpm verify
```

Windows 手工验收：

1. 运行 `pnpm dev`，确认窗口透明、无边框、置顶且任务栏无条目。
2. 拖动窗口主体改变位置，拖动边缘改变大小；退出后重启，确认位置和缩放恢复。
3. 再次运行应用，确认没有第二个窗口，已有窗口被显示并聚焦。
4. 用托盘单击和右键菜单验证显示、隐藏和退出；关闭窗口后确认仍可从托盘恢复。
5. 将窗口移到副显示器，改变分辨率或拔除副显示器，确认窗口完整回到可见工作区。

窗口状态纯函数的单元测试覆盖损坏状态、缩放上下限、多显示器保留、离屏恢复、小工作区缩放和状态往返。
