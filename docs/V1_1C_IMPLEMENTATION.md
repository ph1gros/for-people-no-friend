# GIF Version：V1.1c 版本化角色表现

GIF Version 与 `main` 共享聊天、角色资料和长期记忆能力，但只加载版本化动态 WebP 角色，并把伊雷娜作为第一个角色包。Live2D 保留在主线，两种表现层不在运行时互相切换。

## 伊雷娜资源包

- 53 个素材均为带透明通道的动态 WebP，原始尺寸为 `264 × 264` 或 `500 × 500`。
- 运行时统一放入 `500 × 500` 逻辑画布等比显示，切换动画时不会因原始分辨率不同而忽大忽小。
- 角色包可声明独立画面占比；伊雷娜当前按 `0.78` 显示，使可视边框短边更接近 M3，同时保留用户对整个桌宠窗口的缩放。
- 构建前运行 `pnpm character:catalog`，校验文件签名、动画帧、透明通道、正方形尺寸、数量和通道引用，并生成带 SHA-256 的 `character.json`。
- 文件名会生成情绪、动作、道具、姿势、速度等多标签；`pack.config.json` 只负责稳定的状态、情绪和动作白名单映射。
- 带不透明底色的素材会标记为 `quality:matte-background`，生成器禁止把它们放进活动通道；当前两个探头动画因此保留归档但不参与播放。
- 作者署名为“白之魔女-霜娜”，并记录作者主页、原始动态和用户确认的授权说明。链接只用于归属，不在运行时联网加载资源。

## 安全与回退

角色注册表和资源清单都使用版本 1 schema。Renderer 只接受注册表内的安全相对路径、HTTPS 归属链接、`.webp` 媒体、有限数量和有限尺寸；绝对路径、遍历路径、协议媒体 URL、未知通道和损坏元数据都会拒绝。

WebP 驱动复用既有 `idle / thinking / talking`、情绪和动作控制器。每次资源切换后会扫描首帧透明像素，并与 Live2D 一样更新贴合角色的可视外框。动作播完恢复当前情绪或状态；缺失资源回退到 `neutral` 或 `idle`。表现资源失败时只显示可重试错误，不获得文件系统或网络权限，也不影响本地数据。

## 角色隔离

GIF Version 使用独立的 `character-profiles.webp.v1.json`，只暴露伊雷娜角色槽。首次启动可复制共享配置中已有的伊雷娜资料，但不会改写 Live2D 主线使用的角色文件。

## 通用角色资料整理

“联网查找角色”采用两阶段流程：先用名称和来源作品列出候选，用户选定后再固定发散查询身份、背景、性格、关系以及台词、语音和对白资料。补充页面只接受 HTTPS 和明确允许的资料站点，带超时、取消、响应大小限制与重定向复核；网页正文只在本次整理中交给模型分析，不作为长期原文库保存。

整理结果可包含最多 20 条情境对话示例。这里参考 SillyTavern 的角色卡分层和 RoleLLM 的情境知识思路，把每条示例拆成场景、情绪、触发条件、角色态度和短回应，并关联最直接的资料来源。聊天时只按当前话题挑选最多 4 条，不把整张台词表塞进提示词，也不要求模型机械背台词。旧版普通短台词仍然兼容；称呼、背景、关系、说话方式和来源仍需用户检查并点击“保存”后才生效。找不到可靠字段时保持为空，不用模型常识硬补。

角色配置存储现升级至 v5：旧版内置伊雷娜会分阶段一次性补齐默认资料、普通短台词和结构化情境示例，之后用户清空或修改的内容不会被静默恢复。

SQLite schema 升级到版本 3，把旧的 `default` 会话归入 `default-character`，之后以角色记忆命名空间隔离对话历史和摘要。长期记忆本身继续使用已有 namespace；自动提取水位也改为逐角色记录。切换角色期间若仍在生成回复，会拒绝切换。

## 暂不包含

- 不把动态 WebP 自动转换成 Live2D 骨骼模型。
- 不加入任意目录导入、远程素材下载或 Renderer 文件读取。
- M3 固定角色资料和表现包留在后续 V1.1 工作中。
- Embedding、向量数据库和 Neo4j 参与更完整角色扮演资料库的方案留到 V1.2；V1.1c 继续使用本地结构化角色卡与关键词选择。
- 不加入语音、Agent、MCP、工具调用、屏幕观察、桌面控制或安装包。
