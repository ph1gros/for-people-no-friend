- 首次运行向导：推荐/自定义流程、服务商连接测试、角色导入、可选语音及识别资源、步骤恢复、托盘重跑。已有配置跳过首次向导；资源只在明确选择后安装。
- 合并后保留两项向导修复：等待窗口实际加载成功后再继续，加载失败释放资源并安全回退；角色导入期间阻止重复导航。多音色拆分后，未花安装选择包含完整音色依赖。
- Genie-TTS 组件 1.1.2：Mika（日语）、菲比（中文）、37（英语），独立受管理的本机进程和音色预设；中文到 37 英语使用当前聊天模型翻译，英文原文直接朗读。
- 保留公共句尾终止标记修复、长停顿降噪和取消后队列清理；菲比采用已试听的句尾处理，37 增加保守的短停顿气声处理。
- 资源中心扩为十项，统一用途、语言、依赖、版本、体积和许可说明；新增中英文发音词典、菲比与 37 音色。
- VTube Studio：根据表情名称与参数生成映射建议、标记建议来源；没有确认映射时提供有界通用情绪参数，改进待机过渡。已有确认映射仍优先使用。

## 实际验证

1. `pnpm verify` 完整通过：147 个测试文件、766 项测试，包含 lint、格式、类型检查、生产构建、三个自包含沙箱 Preload、Electron 原生 sherpa 与 SQLite。
2. 真正 Electron 启动检查通过：空配置进入向导并完成后进入主窗口；既有配置直接进入主窗口。两种情况均打开独立资源中心，显示十项资源，窗口间不暴露其他窗口的桥接 API。
3. 独立 Python 运行时执行全部 22 项测试通过，包括短停顿气声、既有长停顿处理、音色及服务边界。
4. 使用生产 `SpeechAssetDownloader` 将 1.1.2 ZIP 安装到隔离目录，激活校验通过。通过实际 `GenieSpeechRuntime` 分别启动并合成 Mika、菲比、37，生成 WAV 分别为 297004、266284、248364 字节。三个进程均拒绝无会话授权请求和不匹配音色请求。
5. 既有真实 PCM 对比：37 的 2.25–2.39 秒 RMS 从 39.186 降至 11.169 LSB，3.96–4.10 秒从 113.379 降至 5.325 LSB；音频长度、前 2.2 秒逐样本保持不变。Mika、菲比固定样本在此次 37 改动前后逐字节一致。用户已试听认可相关菲比和 37 样本。
6. 最终包核对通过：asar 含 3104 项、5 个 sherpa 原生文件解包正确；语音、窗口、IPC、向导代码及全部渲染 HTML/JS/CSS 与验证构建逐字节一致。
7. 对最终 app.asar 使用 Electron 43.4.1 隔离启动器复验首次/升级启动，两条路径通过。最终打包 EXE 的 Node 模式实际调用原生 ASR，将本次 Mika 合成音频重采样为 16 kHz 后识别为“こんにちは 今日はいい天気ですね。”，模型缺失时返回不可用。检查正文，忽略自动标点差异。

## 验收边界

- 向导目前提供未花和伊蕾娜入口；菲比、37 在资源中心安装后到主程序语音设置选择。向导未包含音色试听。
- 没有用真实 API Key 或真实服务商进行联网对话测试；中文到英语翻译链路由假提供商验证。
- 没有将多 DPI、多屏、所有 VTube 模型表现、读屏兼容或全部语句的自然听感记为通过。这些人工验收仍需后续进行。
- 37 全程低频底噪未扩大处理；本次仅对符合保守条件的停顿气声进行衰减，不承诺消除模型生成的所有气声。
- 既有 UI Round 3 的静态模式边框保持原设计；没有擅自选择尚未确定的样式方案。

本地证据集中在 `.release/v1.8.2/` 与 `.release/genie-multivoice/`，不随源码或主程序上传。
