# V1.2 可选资料索引评估

## 结论

V1.2 不安装 Embedding 模型，不连接 Qdrant，也不连接 Neo4j。它们保留为可选接口和以后可以重复运行的评估点，不成为基础聊天依赖。

这不是“以后再说”的空白支票：当前伊雷娜资料已经拆成结构化记录，固定评测覆盖身份、芙兰关系、说话方式、低落安慰和辱骂边界。SQLite 读取后的本地关键词检索为 5/5 命中，聊天每轮最多注入 3 条资料；目前没有证据表明外部索引能抵消安装、启动、权限和故障恢复成本。

## Embedding 接口

`SemanticCharacterKnowledgeRetriever` 只接收当前角色命名空间内已经验证的资料，并只返回记录 ID 与 0～1 分数。关键词结果始终排在前面；非法分数、未知记录、另一角色的记录、抛错或服务缺失都会被忽略并回到纯关键词结果。

自动评测会分别运行纯关键词和“假语义服务故障”两条路径，要求总命中、漏项和平均返回数量完全一致。接口没有实现模型下载、远程请求、API Key 或用户长期记忆索引。

## 向量数据库

当前规模不需要独立向量服务。若将来角色资料达到数千条，并且固定语义改写问题持续漏召回，再比较 SQLite 内嵌向量方案与 Qdrant。候选方案必须满足：

- 关闭或损坏时自动回到关键词；
- 索引可以从 SQLite 正文和来源完全重建；
- 不监听公网，不保存唯一正文，不接触用户长期记忆；
- 对固定评测有可量化提升，而不是只让部署说明变长。

## 关系图

伊雷娜当前人物关系都是单条直接关系，关键词检索可以回答固定关系问题，没有需要 Neo4j 的多跳用例。以后只有出现“人物 A 经事件 B 如何影响人物 C”这类固定测试，而且 SQLite 关系表无法稳定回答时，才实现可选关系检索器。图索引仍只能引用当前角色资料记录，不能把用户关系、作品社区词库和角色世界观混成一张图。

## 自动验收

- 当前五类固定问题全部命中；
- 可选语义接口失败时结果与关键词基线一致；
- 跨角色记录和非法分数无法进入提示词；
- GIF Version 聊天默认返回不超过 3 条、1,400 字；
- 评估不访问网络、不读取真实密钥、不启动外部服务。
