## 已处理

- 样式校验脚本使用 `process`、`console` 时触发 9 个 `no-undef` 错误。补充 Node 内置模块显式导入，并修正新增文件的格式。
- 四条设置样式回归仍要求旧颜色字面量、紧贴模型的洞尺寸及不透明的小组件容器。更新为本轮 token 和无框布局的约定，保留左右镜像、圆角、控件布局、角色高度预留和容器点击穿透断言。没有删除原有 token 重复颜色检查。
- T3 已复现并修复。修复前，计费状态未知时，手动 start 和 resume 各在 30 秒内被暂停三次。修复后，显式启动对当前计费或未知状态记录同意，轮询认可这项同意；确认不计费时仍清除同意。
- T3 两项新回归分别从 start 和 resume 进入真实 manager 控制路径，覆盖未知状态持续 30 秒、未知变计费继续下载，以及随后不计费再变计费必须暂停。原有自动下载失败关闭及从不计费切热点暂停的测试保留。

## 后续：输入显示可读性修正

用户反馈输入小组件文字发糊并明确同意调整后，将 INPUT 标题从 8px 提至 10px、方向键从 9px 提至 11px、鼠标按键从 7px 提至 10px，字重降为 600，复用现有 token 提高文字和边框对比度。键帽随字号适当增大；点击穿透规则、毛玻璃和激活态识别色保留。

独立 Electron 渲染样本中，默认布局约 203×65 → 228×69 CSS 像素。Shift／Control／Space 无文字裁切，240px 容器内无整体溢出；前后各 11880 个命中采样均无输入小组件拦截。此项为渲染检查，不替代 T1 的 Windows 桌面点击穿透验收。对比截图、测量和全检日志位于 `.release/input-legibility/`。
