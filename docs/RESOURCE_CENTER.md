## 当前结果

本轮分类更新：语音引擎（Style-Bert-VITS2、Genie）、基础模型（日语 DeBERTa、Genie 基础模型）、音色模型（伊蕾娜、圣园未花）、语音识别（SenseVoice）。
分类与引擎兼容性由应用内置定义决定，远程目录仅提供展示文字。
伊蕾娜固定显示“仅限非商业使用”，依据用户确认及既有 `resources/PRIVATE_ASSET_NOTICE.zh-CN.txt`；随包保留说明。
该限制不会套用到其他组件。Genie 引擎、基础模型和圣园未花（日语）采用三个独立安装档位。
引擎、BERT、伊蕾娜分别使用 `voice-runtime`、`bert-japanese`、`voice-ireina` 安装目标；全部验证通过才启用朗读。
七项组件均已打包实测并写入冻结信任记录，公开目录、附件与下载路由已同步。

设置新增“资源中心”，支持语音引擎/基础模型/音色模型/语音识别四类、搜索、安装状态筛选、目录刷新、下载进度、安装/暂停/继续/取消。
版本和体积来自 Main 已验证的下载档位；没有匹配的生产资产时明确显示“暂不可安装”，不虚构包大小。
启动只清理孤立下载工作目录，不自动下载第一档。资源中心按钮及用户主动点击麦克风沿用现有下载入口。

参考 BetterGI 资源页 https://bgi.sh/ 的分类导航、列表摘要、独立详情与明确操作位置。
独立窗口采用分类导航加卡片；没有复制 BetterGI 源码、图像或脚本。
这不是任意脚本市场，也没有实现持续订阅、自动更新、卸载或跨会话目录缓存。

## 两个入口

- `FPNF_RESOURCE_CATALOG_URL`：schema 1，仅显示 ID、名称、简介、许可说明、目录最新版本。
- `FPNF_SPEECH_ASSET_MANIFEST_URL`：既有 schema 2，提供已知 ID、与内置记录一致的版本、下载地址。

Main 内置正式入口；环境变量只作为 Main 的显式覆盖，空字符串可停用。正式包只接受 HTTPS，开发可使用回环 HTTP。
Renderer 只有无参数读状态/刷新目录及既有 ID+动作下载控制，不能传入 URL、文件路径或哈希。
目录拒绝未知 ID、额外字段、重复项、超长文本；网络请求禁止重定向，8 秒超时，128 KiB 流式上限。
显示文本使用 `textContent`，不执行远程 HTML。目录失效保留本次会话最后成功结果，首次失败使用内置目录。
已安装资产从当前编译期记录和有效激活标记恢复，未配置下载源时仍可显示。

刷新目录不会安装资源，也不会替换正在下载的任务。元数据中“最新版本”不授权安装；应用只安装内置可信记录支持的版本。
七项组件均有编译期实测记录。远程目录或清单均无法改变这些记录。

## 独立窗口与分类（2026-09-04 更新）

- 本体窗口启用任务栏图标；最小化后可通过任务栏或托盘恢复。
- 设置中的“资源中心”提供打开按钮，托盘也提供同名入口。窗口独立、非模态，可最小化和缩放；重复打开复用现有窗口。
- 只保留“引擎、基础模型、音色模型、语音识别”四类，默认显示引擎。移除“全部资源”导航及旧的朗读/识别两张概览卡；配套依赖留在资源卡说明中。
- 独立窗口使用专用沙箱 Preload，只暴露读取资源状态、刷新目录、控制下载三个方法。Main 只对这三个频道接受资源窗口的主 frame，其他桌宠 IPC 仍只接受桌宠主窗口。
- 下载由 Main 持有，关窗不取消下载；重开后恢复状态。应用退出时销毁资源窗口。
- 下载细条优先显示正在下载的任务，并带上资源名称及其他活动下载数量；没有活动下载时才显示暂停任务。按钮始终控制当前显示的任务。
- 生产构建加入 resource-center.html 和独立的 resource-center.cjs；交互演示页面仍不进入生产构建。

## 本地试用

在项目根目录运行：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174 --strictPort
```

打开 `http://127.0.0.1:5174/resource-center-preview.html`。
页面复用真实资源中心组件及七项名称、说明和版本；安装状态、体积和进度为模拟数据，醒目标注“交互演示”。
可测试分类、搜索、安装、暂停、继续、取消，以及计费网络和目录断网提示；不会下载文件或读取桌宠配置。
页面仅在 Vite 开发环境启用，不在生产 HTML 构建入口中。

## 一致的资源说明

每张卡片固定显示“用途、适配引擎、支持语言、配套资源、版本和下载大小、许可说明”。同类用途使用相同句式；配套资源只说明组合关系，不隐式批量安装。分类、语言、依赖和强制使用限制由本地定义，远程目录只影响展示名称、简介及许可文字。

GitHub Release 允许一次跳转到 release-assets.githubusercontent.com；其他重定向拒绝。Electron 的 net.fetch 手动跳转会失败，因此 Main 用 net.request 取得重定向响应并交回下载器校验，绝不直接 followRedirect。下载内容仍须匹配编译期哈希后才激活。
