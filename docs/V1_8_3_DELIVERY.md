# V1.8.3 交付记录

日期：2026-09-08。

## 更新范围

- 首次运行向导可选择 Mika（日语）、菲比（中文）、37（英语）或伊蕾娜（日语），自动展开相应的固定资源依赖。
- 三种 Genie 音色在全部配套组件校验就绪后支持固定原语言短句试听；伊蕾娜暂不支持向导内试听。
- 修复试听在资源检查或服务启动期间停止不生效、连续试听的取消竞态，以及迟到结果覆盖新播放状态的问题。试听失败不阻止继续设置。
- 两个试听 IPC 通道仅向向导窗口开放；Main 严格限制音色与参数，并持有固定文本和本机服务预设。持久化值 `genie` 继续表示 Mika。
- 内部交接与任务单停止纳入版本库，保留本地文件；修正文档对信任表维护成本的错误描述，保留完整性、目标路径及磁盘检查各自承担的职责。

## 验证与发布测量

1. `pnpm verify` 完整通过：148 个测试文件、778 项测试，包含 lint、格式、类型检查、生产构建、沙箱 Preload、Electron 原生 sherpa 与 SQLite，以及首次／升级启动。版本升级时同步了发布测试中的版本断言。
2. 最终包含 3105 个 asar 条目，5 个 sherpa 原生文件正确解包。全部主进程、桥接及渲染 HTML／JS／CSS 与当前构建逐字节一致；包内版本为 1.8.3。
3. 使用 Electron 43.4.1 对最终 app.asar 运行隔离配置启动检查：全新安装进入向导并完成后进入主窗口；已有配置直接进入主窗口。两种路径均打开十项资源目录，桥接隔离检查通过。
4. 最终打包 EXE 的 Node 模式实际调用原生 ASR，使用既有受控 Mika 音频识别出“こんにちは 今日はいい天気ですね。”；模型缺失时返回不可用。
5. ZIP 完整性检查通过；包内未包含 AstraTTS 试验、音色权重、Python 运行环境、私人角色模型或内部交接文档。
