# V1.9 动作后备与官方创意工坊入口

## 能力范围

| 显示方式       | 点头 / 摇头来源                                                                                                      | 待机行为                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 纯 Live2D      | 优先使用角色包已声明的 `nod` / `shake` 动作；没有映射时，只使用模型实际存在的标准 `ParamAngleY` / `ParamAngleX` 参数 | 已有稀疏自主动作调度可选通用点头；摇头只由明确动作请求触发 |
| VTube Studio   | 保持现有已确认动画热键优先、标准输入参数后备机制                                                                     | 保持原有待机、鼠标跟随和点头节奏                           |
| Live2DViewerEX | 只发送当前角色配置且已核实的动作映射                                                                                 | 保持已配置候选轮换；没有映射时不猜测组名、动作名或数字 ID  |

原生后备动作持续 1.2 秒，每帧以动画当前基线叠加平滑小幅偏移。幅度上限为参数总范围的 10% 与 6 个参数单位中较小者，最终值再次裁剪到模型实际最小值和最大值。没有实际参数、参数范围无效、参数被固定值或口型控制占用时，不提供对应后备动作。标准参数存在并不保证所有模型的视觉方向相同，仍需逐模型验收。

原生后备与已有动作使用同一个队列和冷却机制。已声明动作不因播放失败而偷偷替换为后备；高于待机优先级的引擎动画会拒绝或取消后备。思考、说话、非零口型和窗口内按下交互会取消当前后备；释放指针后可恢复。失焦会取消当前手势并释放按下态，后台待机不会因此永久停用。销毁角色会取消手势及未开始的队列项，之后不再恢复旧模型状态。

这些检查不向 ViewerEX 写入猜测的模型参数，也不要求模型包含某套情绪或动作资产。

## 从官方工坊使用模型

### Live2DViewerEX

1. 在设置的 ViewerEX 面板点击“浏览 Live2DViewerEX 创意工坊”。应用仅请求打开固定的 [官方工坊页面](https://steamcommunity.com/app/616720/workshop/)。
2. 在 ViewerEX 中完成下载；双击控制面板中的模型以加载。模型栏的 `#1` 对应本应用序号 `0`。
3. 选中模型后查看“自定义”中的表情与事件，并结合作者文档或获准使用的明文工程核对真实动作组、动作名和表情 ID。列表位置不能直接当成 ExAPI 数字 ID。
4. 在本应用保存映射后逐项预览。实际回复的待机/恢复流程需要再通过真实对话观察；单次预览不代表整条时序已经验收。

工坊编号仅作标识。此入口不自动下载、解包或导入工坊模型，不读取 LPK 内容。ViewerEX ExAPI 动作/表情接口需要模型自己的标识，项目没有据此获得通用资源清单接口。

### VTube Studio

1. 在设置点击“浏览 VTube Studio 创意工坊”，打开固定的 [官方工坊页面](https://steamcommunity.com/app/1325860/workshop/)。
2. 在 VTube Studio 主菜单的 Steam 入口下载并加载模型，再回本应用连接 VTS、读取模型/表情/动画热键清单。
3. 逐项预览并确认映射。工坊资源由 VTS 管理；浏览按钮不改变当前模型或显示设置。

只有另外获得相应使用许可的完整明文 `.model3.json` 及引用文件，才可通过纯 Live2D 的既有模型导入流程使用。Steam 订阅不等于转存、解包、再分发或将资源随安装包发布的许可。本改动不新增资源下载器，不改变 Cubism Core 的来源与分发要求。

## 安全边界与验证

两个浏览入口都是无 URL 参数的窄 IPC，由 Main 检查可信窗口主 frame 后调用固定 HTTPS 地址。Renderer 不能指定外部 URL、脚本、路径或 Steam item 下载指令。打开失败会显示可恢复提示。

针对性测试覆盖工坊固定 URL、错误结果与非可信 sender 拒绝，设置浏览不修改配置，手势实际范围/保留参数/取消/不叠加、动作优先、口型/交互/状态中断和销毁重用边界。它们不能替代不同实际模型的视觉、口型和拖动验收。

## 官方依据

- [Live2D 标准参数表](https://docs.live2d.com/en/cubism-editor-manual/standard-parameter-list/)：标准头部参数语义；运行时仍读取模型实际范围。
- [ViewerEX ExAPI 接口](https://live2d.pavostudio.com/doc/zh-cn/exapi/api-list/)：动作及表情控制使用模型标识。
- [ViewerEX 直播设置](https://live2d.pavostudio.com/doc/zh-cn/vtuber/live-setup/)：控制面板加载和模型自定义入口。
- [EXStudio Live2D 编辑器](https://live2d.pavostudio.com/doc/zh-cn/exstudio/live2d-editor/)：工程/模型编辑功能，不构成 LPK 提取或资源再分发授权。
- [VTube Studio 官方 Steam 页面](https://store.steampowered.com/app/1325860/VTube_Studio/)：应用及创意工坊入口。
