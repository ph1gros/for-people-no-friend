# V1.8 界面布局实施与验收边界

本文记录 V1.8 第一阶段的目标、非目标、测试接缝和验收证据。V1.8 在当前
V1.7 `fd81cfd` 基线上继续开发；源码、测试和本机开发构建完成不等于已经提交、
打包或发布。

## 1. 本阶段目标

- 让内嵌 Live2D 的实际可见内容贴合角色显示区域底部，消除由画布、容器或背景层
  尺寸不一致造成的底部空隙和黑色底块。
- 让桌面小组件依据 Live2D 的实际占用区域响应式排列，避免遮挡模型腿部；不同窗口
  缩放、窗口比例、对话展开状态和小组件组合不能依赖只适配当前机器的固定坐标。
- 切换角色显示方式或小组件状态时，旧画面必须先完成可观察的退出，再显示新画面，
  不保留重复画布、重复 Spout 画面或一帧以上的旧布局闪现。
- 透明只属于 Live2D 实际显示区域；对话、小组件和设置区域继续使用一致的灰黑色
  表面。不得恢复已删除的折叠对话框或多余实线。

## 2. 测试接缝

本任务明确要求真实行为回归，因此测试通过下列用户可观察边界验证，而不绑定私有
实现：

1. Renderer 根节点的显示模式、面板状态、小组件组合与响应式 CSS 布局契约。
2. Live2D 渲染宿主尺寸变化时，公开布局计算结果与画布最终占位。
3. 显示模式切换的公开生命周期：任一时刻只允许一个角色画面处于可见状态。
4. 开发构建中的真实 DOM/CSS 计算值与截图烟雾检查。

## 3. 验收矩阵

- 缩放：最小、默认、最大桌宠缩放。
- 窗口：对话收起/展开、设置关闭/打开，以及可用的窄/宽布局。
- 小组件：无组件、仅听歌、仅输入、两个组件及不同开启顺序。
- 显示：关闭、内嵌 Live2D、ViewerEX、VTube Studio 的切换路径。
- 视觉：Live2D 区域透明；对话、小组件、设置区域灰黑一致；无底部黑块、腿部遮挡、
  重复画面和已删除控件回归。

自动测试必须先证明旧实现能触发对应失败，再用于验证修复。UI 烟雾检查分别记录
“实际验证”“目视观察”和“未完成”，不能用构建通过代替真实视觉验收。

## 4. 明确不在本阶段处理

- 不扩展 VTube Studio、ViewerEX、语音、麦克风、工作模式或桌面权限。
- 不读取 API Key、私人对话、私人角色、模型或音色内容。
- 不新增运行时插件、外部脚本、远程资源或新的 Main/Preload IPC。
- 未经再次授权，不提交、不推送、不打包、不改标签、不发布。

## 5. 阶段记录

- 基线：`main`、`origin/main` 和 `v1.7` 均指向 `fd81cfd`；开始时工作区干净。
- 根因一：渲染器已经提取了 Live2D 的非透明像素边界，但旧实现只把边界交给小组件
  定位，模型本身仍按资源画布居中。资源内部存在透明下边距时，可见腿部因此悬在
  舞台底边上方。现在默认构图会按真实非透明底边校正到画布边缘；显式 `offsetY`
  继续代表模型作者的构图决定，不做自动覆盖。
- 根因二：小组件预留量按组件类型写死为 60、84 或 128 px，无法反映真实内容高度，
  也不会随窗口比例变化。现在由 `ResizeObserver` 读取组件堆叠实际高度，以当前视口
  45% 为上限同步 Live2D 宿主与灰黑组件底板。
- 根因三：切换到外部显示方式时，Main 可能先启动新画面，Renderer 等保存返回后才
  清理旧 Live2D；保存同一模式还会无条件重载。现在统一为“旧画面退出 → 保存/启动
  新模式 → 新画面进入”，失败恢复旧画面，相同模式不重载。
- 根因四：V1.7 的灰黑遮罩使用固定半窗镂空，没有采用实际 `visible-frame`，组件预留
  变化时会形成错误矩形底块。内嵌 Live2D 现在按真实可见边界开孔；ViewerEX 和
  VTube Studio 仍保留原有外部角色窗，对话、小组件和设置表面保持灰黑。

### 实际验证

- 失败测试先分别捕获底边悬空、固定组件预留和显示模式切换顺序，再完成红到绿。
- 相关回归：4 个测试文件、56 项测试通过。
- `pnpm verify` 通过：103 个测试文件、494 项测试，以及 ESLint、Prettier、两套
  TypeScript 检查、Electron/Renderer 构建和沙箱 Preload 自检全部通过。
- 本机 Electron 开发构建在隔离空白用户目录运行；没有读取真实密钥、对话或私人
  角色资源。临时调试目录与截图在检查后已删除。

### UI 观察

- 1000×650 视口下，双组件实测高度 125 px；Live2D 宿主底边与组件顶边均为
  525 px。
- 720×420 视口下，双组件仍为 125 px；Live2D 宿主底边与组件顶边均为 295 px。
- 两种比例均未检测到区域重叠。对话列表、输入区、组件底板和设置页的实际计算背景
  均为一致的灰黑系；设置页渲染完整，折叠对话入口数量为 0。
- 合成可见帧变量能把 Live2D 镂空精确映射到实际 `top/left/width/height`，组件区
  保持独立灰黑底板。

### 未完成

- V1.7 基础包不带可公开使用的内嵌 Live2D 模型，因此本轮没有用真实模型观察腿部、
  大幅动作和不同模型资源边距；不能把合成可见帧烟雾当成真人模型目视验收。
- 当前 Windows UI 控制入口没有返回原生应用窗口，因此没有执行自动点击式原生验收。
  用户回来后应使用有权使用的模型，至少复核最小/默认/最大缩放、左右角色布局、
  单/双组件、长对话，以及 Live2D ↔ ViewerEX ↔ VTube Studio 连续切换。
- 未提交、未推送、未打包、未改标签、未发布。
