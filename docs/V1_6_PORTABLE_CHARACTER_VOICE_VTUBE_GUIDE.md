# V1.6 小猫角色、伊蕾娜语音与 VTube Studio 复现手册

这份文档完整记录 V1.6 期间对角色卡、VTube Studio 模型表现、中文输入、日语语音生成和便携发布的调教结果。目的不是只解释当前电脑为何能运行，而是让以后维护者只拿到 V1.6 Windows 包和 Steam 版 VTube Studio，也能按同一边界复现。

> 当前发布状态：小黑猫 / heibaiMaoMao 模型和伊蕾娜训练音色的公开再分发授权尚未确认，因此它们不会进入 Git、公开安装包或 GitHub Release。两者已作为标明“待授权”的私人 ZIP 交给当前用户。下文记录已经验证的接入与候选便携方案，供取得授权后复现，不表示当前公开包含有这两个二进制资源。

## 1. 最终组成

V1.6 的“小猫”不是单个模型文件，而是四层配合：

1. FPNF 角色卡决定中文回复的人格、称呼、边界和犯困台词。
2. FPNF Main Process 负责对话、工作模式、记忆、中文到日语的朗读转换、TTS/ASR 请求和全部输入重验。
3. 可选本地语音运行时负责把日语文本生成 WAV；它不参与思考，也不接触角色记忆。当前公开包不含伊蕾娜权重。
4. Steam VTube Studio 负责渲染 Live2D 模型；FPNF 只通过官方本机 Plugin API 发送有限表情、姿态和眼睛参数。

设置页只是控制端。VTube Studio 或声音失败时，中文文字对话、角色卡和本地记忆必须继续可用。

## 2. 小猫角色卡

新安装默认角色名为“小猫”，记忆命名空间为 `character-kitten`。她是原创桌面 AI 搭档，不假定来自任何作品，也不把模型外观误写成官方剧情。

人格基线：安静、敏锐、略微嘴硬；熟悉后主动关心，但不过度撒娇，不在每句话结尾加“喵”。遇到任务时先理解目标，再给一两个可以执行的步骤。资料不足、没有权限或现实感官不可用时直接说明，不能假装看见、记得或已经完成。

语言边界：屏幕文字回复必须为中文；启用伊蕾娜音色后，仅朗读文本转换为自然日语。日语 TTS 不能反过来改变角色的文字语言。

休息行为：超过五分钟没有互动，只允许一次轻微犯困台词，随后进入休息状态，不循环催促。鼠标靠近只表示察觉，眼睛微睁；用户真正发送消息后才完整醒来。

随包的 `resources/character-suite/kitten-character.json` 只用于迁移核对。它不包含对话、长期记忆、摘要、API Key、VTube 授权令牌或本机路径。

## 3. VTube Studio 模型调教

### 3.1 连接方式

FPNF 使用 VTube Studio 官方 Plugin API，默认连接 `127.0.0.1:8001`。另一台电脑首次使用时，必须先在 VTube Studio 主设置页开启“允许插件 API 访问（Allow Plugin API access）”，并让 FPNF 端口与 VTube Studio 括号中显示的实际端口一致；8001 被占用时实际端口可能自动变成 8002 或更高。首次需要在 VTube Studio 弹窗中确认插件授权，令牌只保存在当前电脑的 Windows 安全存储，不随角色包或项目迁移。设置中的“启动 VTube Studio”只调用固定 URI `steam://rungameid/1325860`，Renderer 不能提交任意协议、程序或参数。

“安装模型”是为将来取得许可的模型资源预留的入口，只从安装包固定资源目录复制到 Steam 的 `VTube Studio_Data/StreamingAssets/Live2DModels/FPNF-Kitten`。安装器自动检查默认 Steam 库及 `libraryfolders.vdf` 中登记的库；仅允许 JSON、MOC3、表情、动作和图片等有界模型数据，拒绝符号链接、越界路径、PSD、脚本和可执行文件。当前公开包不带小黑猫模型，因此该入口会明确提示资源不可用。

### 3.2 当前参数基线

| 功能               | VTube 输入参数      | 调教结果                                 |
| ------------------ | ------------------- | ---------------------------------------- |
| 头部左右/上下/侧倾 | `FaceAngleX/Y/Z`    | 三轴缓慢随机，不只机械左右转动           |
| 眼球水平/垂直      | `EyeRightX/Y`       | 水平较明显；向上受限，向下略增强         |
| 睁眼、眨眼、休息   | `EyeOpenLeft/Right` | 随机眨眼、慢闭眼、靠近微睁、消息慢醒     |
| 惊讶等情绪         | 模型表达式/热键     | 先读取清单和逐个预览，再按语义映射       |
| 点头               | `FaceAngleY`        | 普通点头轻；犯困点头更深但时机、深浅随机 |

待机头部参考幅度约为 X `4.2`、Y `2.4`、Z `3.2`，随机过渡约 `2.2～4.8` 秒。自动眨眼间隔约 `2.8～6.5` 秒。入睡闭眼约 `1.8` 秒，收到消息后约 `2` 秒完全睁开；休息时鼠标靠近最多微睁到约 `0.28`。犯困点头首次等待约 `6～12` 秒，之后约 `10～24` 秒，单次约 `2～3.2` 秒，幅度约 `4～7.5`，每次都重新随机。

这些是当前模型的控制基线，不是通用 0～1 模板。换模型必须先读参数最小值、最大值、默认值、表达式和热键；方向反转、范围不同或表达式锁定眼睛时，要单独校准。完整换模步骤见 `V1_6_VTUBE_STUDIO_MODEL_ADAPTATION_GUIDE.md`。

### 3.3 冲突规则

- VTube Studio、人脸追踪和 FPNF AI 接管不能同时抢同一参数。使用 AI 接管时关闭 VTube Studio 人脸追踪。
- 内嵌 Live2D、ViewerEX、VTube Studio 三种显示方式互斥，默认都关闭。
- FPNF 只注入公开参数和表达式，不修改模型源文件或热键配置。
- 对话框、角色和小组件的位置由桌面布局负责，最大缩放限制为 120%；保存前仍做基础避让，防止互相覆盖。

## 4. 伊蕾娜日语 TTS

### 4.1 模型成品

当前音色使用 Style-Bert-VITS2 `2.7.0-JP-Extra`，训练 100 个 epoch，最终检查点为 16040 step，采样率 44100 Hz，单说话人、单 `Neutral` 风格。训练成品原始 Safetensors 的 SHA-256 为：

`7717ef16fdc6b16da43296a9ac7c9f3d434e35622d09d45165b9f79a56c94832`

V1.6 便携运行时使用由同一检查点转换的 ONNX 文件。发布前必须重新记录最终 ONNX、`config.json` 与 `style_vectors.npy` 的 SHA-256，并确认 `config.json` 不含训练电脑绝对路径。

训练原始录音、切片、标注清单和 39GB 训练环境不会随包发布。设置里的“训练音色”仍只为拥有合法音源的用户打开独立训练工具；确认授权是强制步骤。

### 4.2 便携运行时

已经完成并真实测试的候选便携运行时包含嵌入式 Python、Style-Bert-VITS2 运行源码、日语 ONNX BERT、pyopenjtalk 字典、DirectML/CPU ONNX Runtime 和伊蕾娜 ONNX 成品，总体约 1.3GB（未压缩）。它不要求用户另装 Python、CUDA、Git 或训练工具；但因音色公开再分发授权待确认，当前公开包不携带该运行时和权重。

程序只在使用默认本地端点 `http://127.0.0.1:9881/v1`、模型 `style-bert-vits2`、音色 `ireina` 并真正开始朗读时启动固定服务。早期版本误把模型 ID 也写成 `ireina`，V1.7 读取旧配置时会自动迁移。运行时优先 `DmlExecutionProvider`，不可用时回退 CPU。服务只监听 `127.0.0.1`，固定端口 9881；Renderer 不能选择可执行文件、工作目录、参数、主机或端口。退出 FPNF 时由 Main Process 终止随包进程。

真实便携测试中，DirectML 首次加载 BERT 与 TTS 模型需要数秒；测试句首段约 2.8 秒，后续句约 0.8 秒。实际速度受 GPU、驱动、句长和同时运行的声音训练任务影响。CPU 回退能运行，但延迟会明显增加。

### 4.3 语速与停顿

- 默认语速：`0.90`。
- 默认播放音量：`60%`，用户可独立调整。
- 每个日语句子单独生成，边缘各保留约 `40ms`。
- 句间固定停顿约 `90ms`，整段结尾保留约 `280ms`。
- 不再拉伸尾音；省略号会清理成自然停顿，避免句首错误发出“哦”后停住。
- 孤立拉丁字母和常见数学符号在翻译阶段改写成自然日语读法。

屏幕出现一整句后即可开始日语转换与 TTS，不等待整段回复结束。最多并行准备两个片段，但严格按原顺序播放；停止生成、新一轮消息、关闭语音或退出程序都会取消未播放片段和当前口型。

## 5. 中文语音输入

中文识别与日语输出完全分开。ASR 默认端点为 `127.0.0.1:9880`、模型 `SenseVoiceSmall`。当前公开包不携带 ASR 或伊蕾娜 TTS 权重，用户仍可配置自己有权使用的本机或 HTTPS OpenAI 兼容服务。

三种互斥模式：

- 说话就输出：识别到完整一句就自动发送。
- 精准小猫：同一句以“小猫 + 内容”开头才发送，降低误触发。
- 手动录音：点击录音或按住安全键位（默认 F8）说话，识别结果只填入输入框。

连续监听遇到很短间隔时不会让后一句覆盖前一句。用户在上一句结束后 2 秒内继续说，两段文字合并并重新思考；超过 2 秒进入最多四句的有界等待队列。测试只使用合成 PCM、fake 适配器和本地 HTTP，不读取真实麦克风录音或 API Key。

## 6. 新电脑复现流程

1. 从 GitHub Release 下载并解压 V1.6 Windows x64 包；不要把程序放进需要管理员权限的系统目录。
2. 从 Steam 安装 VTube Studio（App ID `1325860`），至少启动一次。
3. 启动 FPNF。新安装自动建立“小猫”角色卡，不导入开发者电脑的聊天或记忆。
4. 在 VTube Studio 中自行放入你有权使用的模型。当前公开包不会安装授权待确认的小黑猫模型。
5. 点击“启动 VTube Studio”，在 VTube Studio 中选择 `FPNF-Kitten`，开启 Plugin API。
6. 回到 FPNF 点击“授权并读取当前模型”，在 VTube Studio 的授权窗口允许一次。
7. 勾选 VTube Studio 显示与需要的鼠标追踪；关闭 VTube Studio 自己的人脸追踪。
8. 打开“语音和语音输入”，配置你有权使用的本机或 HTTPS TTS；若以后取得伊蕾娜公开再分发许可，可再启用文档记录的本机候选运行时。
9. 观察中文文字、语音回退、表情、眨眼、待机、休息与唤醒；没有语音服务时文字聊天仍须完整工作。

如果安装包不含已验证可再分发的模型或音色，对应按钮必须明确显示不可用，不能从开发者电脑、Steam 创意工坊缓存或不明来源自动复制。

## 7. 发布与授权边界

公开 Release 只能包含有明确公开再分发权的模型和音色。“能在本机使用”“来自创意工坊”“开源”或“用户自己训练”都不自动等于可以公开上传二进制。发布前分别记录：作者/权利人、来源 URL、许可证或书面许可、允许的用途、是否允许二次分发和修改。

Style-Bert-VITS2 运行源码按其 AGPL-3.0/LGPL-3.0 文件随包提供；发布说明应链接对应源码。VTube Studio 本体不随包分发，只通过 Steam 启动。FPNF 不分发 VTube Studio 授权令牌。

永不随包发布：API Key、`.env`、`secrets.v1.json`、VTube 授权令牌、用户对话、记忆数据库、摘要、工作区文件、训练原始音频、未确认授权的模型、开发机绝对路径和最近生成的私人朗读文本。

## 8. 发布前验收

- 在一台没有训练环境、没有开发仓库的新 Windows 用户目录中测试。
- 包内不存在 `C:\\ai_deskpet`、开发者用户名、API Key 或令牌文本。
- `pnpm verify` 全量通过，测试只使用 mock、fake、临时数据和本地 HTTP。
- 固定 Steam URI、环回端点、IPC 白名单和 Main 端重验测试通过。
- 随包 TTS 健康检查、首次 DirectML 合成、CPU 回退错误提示和退出清理通过。
- VTube 模型安装只落入已识别的 Steam 库，拒绝符号链接、PSD、脚本和可执行文件。
- 小猫新安装角色卡为中文文字、日语朗读，不携带现有用户记忆。
- 记录 Windows ZIP 的 SHA-256、文件数、压缩/解压大小、提交号、标签和 Release 资产名。
