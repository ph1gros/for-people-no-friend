# V1.9 工作记录

开发记录始于 2026-09-08，基线为既有 main 的 `4e556326ddcfefe6acdf3f54682f74ac5c60ca55`，对应 v1.8.3。本页保留实现细节和历史证据；当前发布范围、验证、提交和缺项统一见 [V1.9 交付记录](V1_9_DELIVERY.md)。

## 范围与收尾决定

本轮先获授权推进小组件 A–D、Astra 隔离研究和显示端情绪改造；随后用户确认资源上传到 `ph1gros/fpnf-resources`、补充具体来源、按非商用用途整理，并要求收尾除人工复测外的工作。

2026-09-08 的收尾决定完成 E 期政策留痕：安全规范 §6.2 允许经审阅、测量、内置信任锚约束的声明式纯数据包下载，保留禁止脚本、任意 ZIP 导入、目录扫描、远端信任依据与新增高风险数据源。§6.3 保留已有正确的哈希与目标保护，不采用旧交接中不成立的成本论证。

2026-09-08 收尾时，资源仓库的说明更新和预览资源发布已完成，主程序改动尚未提交或打包。2026-09-13 用户授权完成 V1.9 提交、推送、打包和发布，并要求将无法完成的项目明确列出。最终结果以交付记录为准。Embedding、持久关系演化、传统 OneDrive VITS/MoeGoe 和第三方可执行插件不因发布授权而自动成为已实现能力。
