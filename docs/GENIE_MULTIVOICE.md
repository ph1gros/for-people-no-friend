## 2026-09-06 菲比“比”后吸气修正

用户定位原试听第一句“你好，我是菲比”的“比”后吸气。旧规则为保护尾字，在强发音后额外保留 200 ms，目标气声恰好在这个范围内；重复运行旧处理仍保持 RMS 68.10，复现失败断言。

新规则仅对菲比开启：在原有长停顿内，检查保护区中的极弱、非周期、低频尾声；检测到正常周期发音或高频辅音就继续保留完整窗口。保留至少 40 ms 尾部及渐变衰减，不修改模型或参考录音。

同一份 PCM 对照：2.12–2.24 秒目标区间 RMS 从 68.1013 降至 1.8781；1.30–2.06 秒逐采样不变，全长保持 6.40 秒。本地 ASR 对照均为“你好，我是菲比。今天的天气很好，我们一起出去散步吧。”。

试听和证据：`.release/genie-multivoice/feibi-breath-reduced.wav`、`feibi-breath-result.json`、`asr-breath-compare.json`；本地复现入口为 `check-feibi-breath.py`。新增回归同时保护轻声元音和高频无声辅音；听感仍由前后试听确认。

引擎组件 1.1.1 已重新测量并更新编译期锚点，经生产安装器更新到隔离目录，再由 Main 启动菲比服务完成真实合成（WAV 284204 字节）；鉴权与错误音色拒绝检查通过。证据为 `install-breath.log` 和 `install-breath-result.json`。本轮 14 项 Python 回归及 17 项相关 TypeScript 测试通过，Electron 构建通过；`pnpm verify` 仍被原有四个 VTube／交接文件格式问题阻断。没有发布应用或上传资源。
