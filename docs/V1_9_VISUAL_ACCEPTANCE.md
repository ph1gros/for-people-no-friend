# V1.9 人工验收清单

当前基线见 [v1.8.3 交付记录](V1_8_3_DELIVERY.md)，下一阶段范围见 [V1.9 计划](V1_9_PLAN.md)。以下项目需要人工观察或试听，不能以自动测试代替。

- 独立资源中心和任务栏图标：多次打开、最小化、恢复及关闭后的下载状态。
- 100%／125%／150% DPI、多屏切换、窄屏及窗口拖动时的面板、卡片和按钮布局。
- 内嵌 Live2D 的独立 GPU 与强制软件渲染；下载、解压与故障恢复期间的实际帧率观感。
- VTube Studio 人工授权、Spout2 输出、模型表情和口型的实际桌面效果。
- Mika 多句日语及不同情绪的自然度；检查停顿降噪是否影响特别轻的发音。保留原音频、处理后对照与新安装试听。
- 向导三种 Genie 音色的实际试听、停止、切换与离页行为；组件未就绪提示，以及纯键盘操作和读屏体验。
- AstraTTS 同文本完整生成与流式的连续听感；尤其复查开头词内卡顿和分块接缝。研究样本满意后，正式接入仍需独立验收。
- 需要真实账户的在线 Fish Audio／OpenAI TTS 与中文转日语服务，使用者自行配置凭据后再做实际试听。

传统 OneDrive VITS/MoeGoe 音色保持暂缓，并不属于本轮已交付组件。后续扩展单独评估兼容性和许可。
